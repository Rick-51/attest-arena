# Attest Arena 后端接口文档

> 前端对接说明。Base URL：`http://localhost:3000`（`PORT` 可配）。

## 0. 重要架构约定（前端必读）

- **用户的交易由前端用用户钱包（MetaMask）直接发到合约**，后端**不代签**。因为合约里 `joinFaction` / `proposeSwap` / `acceptSwap` / `cancelSwap` / `claimReward` / `bet` 都用 `msg.sender`（= 发交易的钱包）做身份。
- **后端只做**：只读查询 API、管理端写 API（owner 操作）、价格 worker。
- **统一枚举**：
  - `coinId`：`0`=BTC，`1`=ETH，`2`=CTC
  - `pointType`：`0`=A 积分(BTC)，`1`=B 积分(ETH)，`2`=O 积分(CTC)
- **金额/价格**：合约里都是原始 `uint256`（无小数），前端按约定单位自行换算（价格建议 8 位小数定点）。接口返回一律是**十进制字符串**（避免 JS 大数精度丢失）。

## 1. 认证（可选，用于后端鉴权的接口）

| 方法 | 路径 | 请求体 | 返回 |
|---|---|---|---|
| POST | `/api/auth/nonce` | `{ wallet: "0x..." }` | `{ wallet, nonce }` |
| POST | `/api/auth/login` | `{ wallet, signature }` | `{ token, wallet }` |

- 流程：拿 nonce → 前端用钱包对 `"Attest Arena 登录验证: <nonce>"` 签名 → 提交换 token。
- token 后续放请求头 `Authorization: Bearer <token>`。

## 2. 只读查询接口（公开）

### 2.1 阵营 `/api/factions`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/factions` | 阵营数组 `[{ id, name, coinId, treasury, memberCount }]` |
| GET | `/api/factions/:id` | 单个阵营 `{ id, name, coinId, treasury, memberCount }` |
| GET | `/api/factions/member/:address` | `{ address, factionId }`（factionId=0 表示未加入） |

### 2.2 积分 `/api/points`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/points/balance/:address` | `{ address, A, B, O }`（A/B/O 都是字符串） |
| GET | `/api/points/proposals` | OTC 兑换提议数组 |
| GET | `/api/points/proposals/:id` | 单个提议 `{ id, proposer, counterparty, fromType, fromAmount, toType, toAmount, accepted, cancelled }` |

### 2.3 价格 `/api/price`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/price/:coinId` | `{ coinId, price, timestamp }` |
| GET | `/api/price/:coinId/at/:index` | 历史某条 `{ coinId, index, price, timestamp }` |
| GET | `/api/price/:coinId/history/count` | `{ coinId, count }` |

### 2.4 结算 `/api/settlement`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/settlement/status` | `{ totalPrizePool, settled }` |
| GET | `/api/settlement/rewards/:address` | `{ address, reward, score }` |

### 2.5 预测押注 `/api/prediction`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/prediction/config` | `{ stakeAmount, rewards: { first, second, third, rest } }` |
| GET | `/api/prediction/rounds` | 轮次数组 `[{ id, coinId, startPrice, resolved }]` |
| GET | `/api/prediction/rounds/:id` | 单轮 `{ id, coinId, startPrice, resolved }` |
| GET | `/api/prediction/rounds/:id/has-bet/:address` | `{ roundId, address, hasBet }` |
| GET | `/api/prediction/rounds/:id/bets` | `{ roundId, count, bets: [{ bettor, isUp, targetPrice }] }` |

### 2.6 排行榜 `/api/leaderboard`
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/api/leaderboard` | `{ factions: [{ id, name, coinId, memberCount, treasury, score }] }`（按 score 降序） |

### 2.7 健康检查
| 方法 | 路径 | 返回 |
|---|---|---|
| GET | `/health` | `{ ok: true, network, chainId }` |

## 3. 管理端接口 `/api/admin`（owner 操作）

> 需要请求头 `Authorization: Bearer <ADMIN_KEY>`（若后端没配 `ADMIN_KEY` 则跳过校验）。

| 方法 | 路径 | 请求体 | 说明 |
|---|---|---|---|
| POST | `/api/admin/factions` | `{ name, coinId }` | 建阵营（钉币） |
| POST | `/api/admin/config/entry-fee` | `{ fee }` | 设入场费（tCTC wei） |
| POST | `/api/admin/config/mint-amount` | `{ amount }` | 设入场铸积分数 |
| POST | `/api/admin/game/start` | — | 开局 |
| POST | `/api/admin/game/end` | — | 结束 |
| POST | `/api/admin/prize/capture-start` | — | 记录起始价（结算前） |
| POST | `/api/admin/prize/deposit` | `{ amount }` | 充值奖池（tCTC，"1"=1 tCTC） |
| POST | `/api/admin/prize/settle` | — | 最终结算（只能一次） |
| POST | `/api/admin/prediction/rounds` | `{ coinId }` | 开预测轮，返回 `{ ok, roundId }` |
| POST | `/api/admin/prediction/rounds/:id/resolve` | — | 判题结算一轮 |
| POST | `/api/admin/prediction/config` | `{ stakeAmount, first, second, third, rest }` | 设押注额 + 奖励 |
| GET | `/api/admin/status` | — | `{ isActive, isFinished, settled }` |

## 4. 前端需直接调用的合约函数（用户自己的交易，非后端 API）

这些由前端用 **wagmi/viem + MetaMask** 直接发交易，后端不参与：

| 合约 | 函数 | 说明 |
|---|---|---|
| `FactionRegistry` | `joinFaction(uint256 factionId)` **payable** | 进阵营，`value` = 入场费（读 `entryFee()` 得到） |
| `Points` | `proposeSwap(counterparty, fromType, fromAmount, toType, toAmount)` | 发起兑换提议（托管积分） |
| `Points` | `acceptSwap(proposalId)` | 接受兑换提议 |
| `Points` | `cancelSwap(proposalId)` | 撤回兑换提议 |
| `PrizePool` | `claimReward()` | 领取结算奖励 |
| `Prediction` | `bet(roundId, isUp, targetPrice)` | 押注（扣 stakeAmount 积分） |
